🔬 Research: Adapting Foundation Models for Dental Caries Detection in Mixed Dentition Using Dual-View Co-Training

DINOv2 ResNet-50 FPN Faster R-CNN Mask R-CNN SVM
  • Developed a dual-view AI framework for automated dental caries detection in pediatric mixed-dentition panoramic OPG images.
  • Designed a Global-View Screening module using ResNet-50 FPN and Faster R-CNN to generate high-recall suspicious candidate regions.
  • Implemented a Local-View Tooth-Level Inspection module using Mask R-CNN for tooth segmentation and detailed lesion verification.
  • Leveraged DINOv2 foundation model features and SVM classification for robust caries identification.
  • Integrated both views through dual-view co-training to combine global anatomical context with fine-grained tooth-level analysis.
